# The-simplest-throw-simulation
This repository contains a simple simulation of motion accounting for air resistance on Python with visualisation provided by tkinter
## Work-in-progress features:
### Metrics - Completed!
The measurement system will be converted to metric in the near future
### Dynamic coefficient
Air resistance coefficient will be calculated by changeable characteristics: sail area of the moving object, air density, mass of the moving object
### Liquid simulation
The model will be able to calculate the simplified trajectory of flying liquids
### Explosive objects
The model will be able to calculate the simplified trajectory of objects that explode mid-flight.
